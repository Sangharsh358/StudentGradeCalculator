\# Student Grade Calculator



A simple Java project to calculate the total marks, percentage, and grade of a student.



\## Features

\- Accepts marks for three subjects

\- Calculates total marks

\- Calculates percentage

\- Displays the student's grade



\## Technologies Used

\- Java

\- Git

\- GitHub



\## How to Run



Compile the Java program:



```bash

javac StudentGradeCalculator.java

```



Run the program:



```bash

java StudentGradeCalculator

```



\## Grade Criteria

\- A: 75% and above

\- B: 60% to below 75%

\- C: 50% to below 60%

\- D: 40% to below 50%

\- F: Below 40%
